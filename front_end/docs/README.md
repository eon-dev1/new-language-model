# NLM Front-End Documentation

The NLM front-end is an Electron desktop application (React + TypeScript) for managing Bible translation projects — Bible reading/verification, dictionary management, and grammar/notes ("Memories").

See the [repo root README](../../README.md) for setup (npm install, Python venv, MongoDB credentials, `npm run dev`).
